# Veritalex - Night
A DARK Material 3 reading app companion. Set color mode DARK. Reuse all layouts from Veritalex Reading Refined.
Use near-black warm brown surfaces, soft warm ink text, muted supporting text and peach amber actions. All surfaces, dialogs, app bars, navigation bars, input backgrounds and sheets are dark. No bright white cards. Keep book cover art unchanged.
Roboto Flex for every UI title, label, control and metadata; Literata only for actual book prose and meaningful quote excerpts. UI title 24/32 medium, section 20/28 medium, body 16/24, supporting 14/20. Reader prose 19/32. Sentence case.
Strict native Android Material 3 components, semantic color roles, 48dp targets; 16dp cards, 28dp sheets, pill main actions. Tone-separated groups and subtle dividers instead of dense card walls. No gradients or decorative metrics.
Home, Explore, Library are the three destinations; Library contains Books, Shelves, Journal; Settings is a toolbar action. Reader hides destination navigation. Keep complete native status and gesture safe insets.
